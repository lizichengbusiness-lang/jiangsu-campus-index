# 五省院校索引

网站收录江苏、广东、山东、山西和浙江的普通高校。浏览器直接打开 `index.html` 即可使用。在线版由 GitHub Pages 从仓库根目录发布。

- `index.html` 页面结构
- `styles.css` 样式和移动端布局
- `app.js` 检索、筛选、院校详情、收藏和 CSV 导出
- `schools.js` 来源和院校数据，每行对应一所院校，按学校标识码保存收藏

学费记录包含年份、出处和人民币元/生/年的收费档位。专项收费标注 `special: true`。加权均值的 `average.scope` 说明生源地、年份、项目类别和覆盖人数。没有可核实的学费时，页面和 CSV 均显示「暂无信息」。

`admissions` 收录有公开来源的 2026 年艺体招生类别和项目，实际报考以学校和省级考试院当年信息为准。历史一本、二本对应江苏 2020 年普通类文科及理科平行志愿投档记录。
