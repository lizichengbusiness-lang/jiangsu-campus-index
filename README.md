# 江苏院校索引

浏览器直接打开 `index.html` 即可使用。在线版由 GitHub Pages 从仓库根目录发布。

- `index.html` 页面结构
- `styles.css` 样式和移动端布局
- `app.js` 检索、筛选、院校详情、收藏和 CSV 导出
- `schools.js` 源链接和院校数据，每行对应一所院校，学校标识码用于收藏索引

学费记录包含年份、出处和人民币元/生/年的收费档位。专项收费标注 `special: true`。加权均值的 `average.scope` 说明生源地、年份、项目类别和覆盖人数。学费空白项提供按校名搜索的链接。

`admissions` 记录 2026 年已核验的艺体类招生类别、项目和出处。历史批次字段对应江苏 2020 年普通类文科及理科平行志愿投档记录。
